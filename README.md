Entry for the [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty on make.fun (referral code: `8dxq9bq0`).

The program writes one two-part micro-confession to `/output/entry.txt`: a
`To:` line naming who the message was meant for, and the unsent message
itself, exactly as it was typed — a confession to Mum about a job lost in
March, typed every Sunday after her call and deleted, because lying about
work is easier than hearing her voice go quiet with worry.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory.
